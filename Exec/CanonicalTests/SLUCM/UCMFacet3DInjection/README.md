# UCMFacet3DInjection — Phase 2.7 Canonical Test

## Overview

Tests ERF-SLUCM Phase 2.7 Facet3D BEP-Continuous-TF implementation:
- **BEP-style geometric overlap** for wall injection (vs Phase 2.6 exponential)
- **Sharp roof placement** at the cell containing H_mean
- **Terrain-following coordinates** support (proof of concept on flat terrain)
- **Optional continuous Gaussian height distribution** (switchable via ParmParse)
- Maintains **backward compatibility** with Phase 2.5 and Phase 2.6

## Setup

### Domain
- ATM: 4×4 (horizontal), 256 vertical cells
- Grid ratio: 4 → UCM 16×16
- Δz = 4 m, peak = 1024 m
- Flat terrain (proof of concept; terrain-following coordinates implemented but not tested)

### Buildings (Two Vertical Stripes)
Generated by `gen_csv.py`:

| Stripe    | ATM i | UCM i   | Height | Plan Area Frac | Urban Frac |
|-----------|-------|---------|--------|----------------|-----------|
| Left      | 0–1   | 0–7     | 30 m   | 0.60 (dense)   | 1.0       |
| Right     | 2–3   | 8–15    | 5 m    | 0.20 (sparse)  | 1.0       |

Both stripes extend across all j cells (uniform in y).

### Rationale
- **Height ratio 30:5 = 6:1** — tests different overlap fractions
- **Tall building in 7–8 ATM cells** (30m / 4m per cell) — sufficient vertical resolution
- **Short building in 1–2 ATM cells** (5m / 4m per cell) — edge case testing
- **Plan area mismatch (0.6 vs 0.2)** — tests lambda_f * wall_fraction accounting

## Running the Test

```bash
cd build
cmake -DERF_ENABLE_UCM=ON ..
make -j UCMFacet3DInjection
cd ../Exec/CanonicalTests/SLUCM/UCMFacet3DInjection

# Generate building layout
python3 gen_csv.py

# Run simulation (2 steps)
mpirun -n 1 ./erf_ucm_facet3d_injection inputs

# Verify outputs
python3 check_facet3d.py
```

### Inputs (inputs file)
Key Phase 2.7 parameters:
```
erf.ucm.use_facet3d_injection            = 1    # Phase 2.7 on
erf.ucm.use_gaussian_height_distribution = 0    # sharp mode (default)
erf.ucm.height_std_threshold_m           = 0.1  # Gaussian threshold
erf.ucm.H_bldg_uniform                   = 10.0 # defensive default (CSV overrides)
erf.cfl                                  = 0.5  # stability (NOT fixed_dt!)
erf.ucm.ucm_atm_plot_int                 = 1    # write ATM plotfile every step
erf.ucm.ucm_debug                        = 1    # verbose debug output
```

## Verification Script (check_facet3d.py)

Asserts (exit code 0 = PASS, 1 = FAIL):

1. **9 plotfile components** (vs 8 in Phase 2.6)
   - `H_wallroof_atm` ABSENT (Phase 2.6 combined field)
   - `H_wall_atm` PRESENT (new Phase 2.7)
   - `H_roof_atm` PRESENT (new Phase 2.7)
   - Others: `f_urb, H_bldg_mean, H_bldg_std, lambda_p, lambda_f, H_atm, H_road_atm`

2. **Height split by stripe**
   - Left (i=0..1): 25–35 m (expect ~30)
   - Right (i=2..3): 2–8 m (expect ~5)

3. **Flux conservation** (BEP split rule within 5%)
   ```
   H_atm ≈ H_road_atm*(1-lambda_p) + H_wall_atm*lambda_f + H_roof_atm*lambda_p
   ```
   - Tests that geometric overlap correctly partitions sensible heat

4. **Phase 2.7 structure** — forbidden field check
   - `H_wallroof_atm` must not appear

## Physics References

1. **Martilli, Clappier & Rotach (2002)** — *Boundary-Layer Meteorology* 104:261–304
   - "An urban surface exchange parameterisation for mesoscale models"
   - Section 2: BEP geometry (building representation)
   - Section 3: Heat equations (wall, roof, street energy balance)
   - Phase 2.7 uses their geometric overlap formula: `overlap(k) / H_mean`

2. **Coceal & Belcher (2004)** — *QJRMS* 130:1349–1372
   - Motivation for continuous height distribution in urban canopies
   - Gaussian PDF provides smoother injection vs discrete buildings

## Known Limitations

- **Test does NOT exercise terrain-following coordinates** (flat terrain only)
  - Terrain-following code is implemented and tested separately (not in this canonical test)
  - Proof of concept deferred to future integration test

- **Test does NOT exercise H_bldg_std > 0.1 m** (Gaussian mode)
  - CSV currently sets all buildings to zero height std
  - Gaussian mode tested via optional `check_facet3d_gaussian.py`
